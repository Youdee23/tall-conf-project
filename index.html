TaLL Conf

A friendly coding conference for budding builders of websites, apps and useful digital tools

Oh, come, oh ye learners!

TaLL Conf brings curious students together for practical sessions, simple projects and conversations about learning technology one step at a time

OPENING KEYNOTE

Start with a big idea

Meet the conference host and hear how simple websites can solve real problems in schools, businesses, and communities

HTML AND CSS LAB

Build your first layout.

Practice headings, buttons, images, spacing, units, and flexible rows while building a real conference page.

TEAM BUILD

Turn a rough sketch into a page.

Work with a partner, create a hero, CTA, the sections, and translate the design into clean HTML and CSS.

DESIGN REVIEW

Make it clear and readable

Check font sizes, contrast, image effects, section spacing, and whether the page still works on a smaller screen

DEMO DAY

Show what you built.

Present your one-page site, explain your layout choices, and share one CSS skill you're proudest of using this project.
